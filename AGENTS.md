# Agent instructions

This repository contains the Iris layout, themes, mods, and tools for Herdr.
A mod is a custom Herdr component.
See [README.md](README.md) for setup and an overview.

## Change the files

- Edit source files in this repository before you copy changes to a live Herdr installation.
- Read `~/.config/herdr-app/AGENTS.md` before you change Herdr behavior.
- Do not edit files generated by Herdr.
- Do not edit mods that ship with Herdr.
- Do not edit the layout state that Herdr manages.
- Keep support for Codex and Claude Code aligned when both providers supply reliable data.
- Do not use em dashes in project writing or interface text.

## Make sure that changes work

- For relevant code changes, run `python3 -m unittest discover -s tests -v`.
- For each changed mod, run `herdr-app check mods/<mod-name>`.
- For each changed mod, inspect the result in Herdr.
- Run `python3 scripts/sync.py` to preview changes to live files.
- Run `python3 scripts/sync.py --apply` to copy the changes.
- If the sync tool reports a conflict, do not overwrite the live change.

## Git

- Do not push to a real remote or a default branch.
- Keep each commit small and focused.
- Use `type(scope): summary` for each commit message.
- Edit `AGENTS.md` to update both instruction files.

`CLAUDE.md` is a symlink, a file that points to `AGENTS.md`.
